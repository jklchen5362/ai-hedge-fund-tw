常見問題與解答 (FAQ)

Q1: 如何開始使用 AI 評估股票？
A: 開啟 App「分析」首頁，在輸入框輸入台股 4 碼代號（如 2330 或 2330.TW）或美股代號（如 NVDA、AAPL），點擊「新增」後按下「開始評估」，系統即會在數秒內並行調用 AI 矩陣計算交易評級與多空分數。
Q2: 如何恢復 Pro 會員購買 (Restore Purchases)？
A: 若您更換新裝置或重新安裝 App，請在 App 內點擊「升級 Pro」看板，並點擊下方「恢復購買」按鈕；或至「系統設定」>「恢復已購買權限」，系統將透過您的 Apple ID 自動恢復權益。
Q3: 如何管理或取消自動續訂訂閱？
A: 您可以隨時透過 iOS 裝置的「設定」>「頂部您的 Apple ID」>「訂閱項目」中找到「台股智投 Pro」，點選即可變更方案或取消訂閱。請注意需於目前計費週期結束前至少 24 小時前取消。
Q4: 終身買斷版是否支援家人共享？
A: 是的，「台股智投 Pro 終身買斷版」支援 Apple 家人共享功能。您只需購買一次，即可與您「家人共享」群組中的最多 5 位家庭成員共同使用完整 Pro 功能。
Q5: 數據分析是否需要額外付費設定 API Key？
A: 不需要！本 App 內建全套量化規則與本地端多代理人模型，無需提供任何 API 金鑰即可完整運算。若進階使用者想接入自己的 OpenAI 或 Gemini 模型，亦可於「系統設定」中自由輸入。
